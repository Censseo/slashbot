## Layer Pattern

**Role**: Pure domain services shared across multiple plugins. These files contain business logic with no plugin SDK coupling — they are plain TypeScript classes that plugins instantiate and register via `context.registerService()`.

**Convention**: One class per file, file named `kebab-case.ts` matching the class name. Services are always instantiated in the owning plugin's `setup()` and injected where needed.

**Canonical code example** (from `memory-store.ts`):
```typescript
export class MemoryStore {
  constructor(workspaceRoot: string) { ... }
  async search(query: string, limit?: number, graph?, expand?): Promise<MemoryHit[]> { ... }
  async upsert(entry: MemoryUpsertInput): Promise<{ path: string; line: number }> { ... }
}
```

## Expected Errors

| Error | From | Handling |
|-------|------|----------|
| `ENOENT` on `graph.load()` | `fs.readFile` | Caught — empty graph is valid initial state |
| `ENOENT` on `store.listFiles()` | `fs.access` | Caught — file simply omitted from index |
| Path escape in `store.get()` | `relative()` returning `..` prefix | Thrown as `Error('Path escapes memory directory')` |
| JSON parse failure in JSONL load | Malformed line | Caught per-line — skip and continue |
| LLM extraction failure | `extractAndMerge()` try/catch | Swallowed silently |
| Flush I/O error | `flush()` scheduled timer | Logged as `{}` (no-op catch) |

## Guard Rails

- **DO NOT** couple service classes to the plugin SDK (`SlashbotPlugin`, `PluginContext`). Services are plain classes.
- **DO NOT** call `graph.load()` more than once per `AssociationGraph` instance — duplicate load accumulates duplicate edges.
- **DO NOT** use `graph.slugify()` as a persistence key for user-visible labels — it is lossy (lowercase, punctuation stripped).
- **DO NOT** pass `null` as `llmAdapter` for prod flows — `extractAndMerge` checks for null but extraction is silently skipped, causing graph to remain empty.
- **DO NOT** add services here that have plugin SDK imports — move to the plugin's own directory.
- **Edge weight is read-only externally** — only `addEdge()` and `insertEdge()` modify weights.

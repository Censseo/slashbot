## Layer Pattern

Architectural role: Full-screen terminal UI built with @opentui/core. Provides panels for chat, input, communication logs, command palette, diff display, and model selection. Second largest plugin (15 files).

File convention: `panels/` for UI components, `adapters/` for I/O redirection

```

├── index.ts                       # TUIPlugin class
├── TUIApp.ts                      # Main TUI orchestrator
├── borders.ts                     # Border style definitions
├── pasteHandler.ts                # Clipboard paste processing
├── adapters/
│   └── OutputInterceptor.ts       # Redirects stdout to ChatPanel
└── panels/
```

## Guard Rails

| Rule | Reason |
|------|--------|

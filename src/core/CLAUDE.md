## Code Patterns

### Dependency Injection

**When to use**: All shared services must be DI-injectable.

```typescript
// Register service (in container.ts or plugin init)
container.bind(TYPES.EventBus).to(EventBus).inSingletonScope();
container.bind(TYPES.ConfigManager)
  .toDynamicValue(() => createConfigManager())
  .inSingletonScope();

// Resolve service
const eventBus = container.get<EventBus>(TYPES.EventBus);
```

**File reference**: `src/core/di/container.ts`

### Typed Event Emission

**When to use**: All inter-module communication.

```typescript
// Emit typed core event

// Subscribe with auto-unsubscribe

  console.log('File edited:', event.filePath);
});
unsub(); // Cleanup
```

## Error Handling

**Pattern**: Try-catch with display service fallback

```typescript
try {
  await operation();
  display.successText('Operation complete');
} catch (error) {
  const msg = error instanceof Error ? error.message : String(error);
  display.errorBlock(msg);
}

// Graceful degradation for config loading
try {
  const file = await Bun.file(CONFIG_FILE).json();
} catch {
  // Config doesn't exist yet - use defaults
}

// Abort handling for streaming
if (error.name === 'AbortError') {
  return; // Silent exit on abort
}
```

## State Machines & Lifecycle

### Agentic Loop Lifecycle

**States**: idle -> streaming -> action_parsing -> action_execution -> result_assembly -> (loop or done)

```text
idle -> streaming: User input received
streaming -> action_parsing: LLM response complete or tool call received
action_parsing -> action_execution: Actions extracted from response
action_execution -> result_assembly: All actions executed
result_assembly -> streaming: More iterations needed (loop back)
result_assembly -> idle: Max iterations or no more actions (done)
```

**Valid Transitions**:

| From | To | Trigger | Guard Condition |
|------|----|---------|-----------------|
| idle | streaming | User input | API key configured |
| streaming | action_parsing | Response received | Content contains action tags or tool calls |
| action_execution | streaming | Actions have results | iteration < MAX_ITERATIONS |
| result_assembly | idle | Loop complete | No more actions or max iterations reached |

**Invalid Transitions (MUST reject)**:

| From | To | Reason |
|------|----|--------|
| idle | action_execution | Cannot execute without parsing first |
| streaming | idle | Must complete action cycle before returning to idle |

## Guard Rails

| Rule | Reason | Source |

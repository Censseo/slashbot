## Expected Errors

| Error | Handling | Context |
|-------|----------|---------|
| AbortError | Silent return (user cancelled) | Streaming interrupted |
| API auth failure | Display error, prompt for key | Invalid/expired API key |
| Rate limit (429) | Retry with backoff | Provider rate limiting |
| Network timeout | Display error with retry hint | TIMEOUT_MS exceeded (120s) |
| Max iterations | Return accumulated results | Agentic loop safety limit |

## Guard Rails

| Rule | Reason |
|------|--------|
| DO NOT call provider APIs without going through LLMClient | Breaks auth, tracking, and streaming pipeline |
| DO NOT exceed MAX_ITERATIONS (10000 CLI, 10000 connector) | Prevents runaway agentic loops |
| DO NOT store API responses with sensitive user data | Privacy requirement from constitution |

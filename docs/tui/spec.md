## Overview

The terminal UI is a full-screen interface built with `@opentui/core`, providing a rich interactive experience with panels for chat, input, communication logs, command palette, and header status. The TUI includes an output interceptor that redirects stdout/console to the chat panel, a sidebar built dynamically from plugin contributions, and support for image paste, diff display, and model selection modals.

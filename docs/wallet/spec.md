## Overview

The wallet domain covers $SLASHBOT token economics on Solana, including the built-in Solana wallet, proxy billing system, real-time pricing, credit management, and token redemption. Users can pay for Grok API calls with $SLASHBOT SPL tokens instead of managing API keys directly. The proxy at getslashbot.com routes authenticated requests to X.AI.

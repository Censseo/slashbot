> Generated by /specforge.setup-docs on 2026-02-12

## Overview

Connectors bridge Slashbot to different platforms. Each connector implements the `Connector` interface, handling platform-specific message formatting, input/output routing, and connection lifecycle. Messages are automatically split at platform-specific limits with smart splitting at newlines/spaces. The connector source type is intentionally extensible for third-party plugins.

## Supported Platforms

| Platform | Library | Message Limit | Markdown |
|----------|---------|---------------|----------|
| CLI | OpenTUI REPL | Unlimited | Full |
| Telegram | Telegraf | 4096 chars | MarkdownV2 |
| Discord | discord.js | 2000 chars | Discord markdown |

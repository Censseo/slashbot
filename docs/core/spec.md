## Overview

The core engine is the backbone of Slashbot, providing the foundational systems that all plugins and connectors depend on. It includes the API client (Grok integration with streaming and tool use), the action system (XML tag parsing and execution), dependency injection (InversifyJS container), the event bus (typed pub/sub), prompt assembly (dynamic system prompt from plugin contributions), command registry, and application lifecycle (REPL loop, signal handling, auto-update).

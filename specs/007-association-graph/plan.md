# Implementation Plan: Association Graph for Memory

**Branch**: `007-association-graph` | **Date**: 2026-03-09 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/007-association-graph/spec.md`

## Summary

Add a knowledge graph layer to the memory plugin. A new `AssociationGraph` service provides in-memory graph storage (JSONL persistence), BFS/Dijkstra traversal, and auto-extraction of concepts from upserts via LLM. Three new tools (`memory.associate`, `memory.related`, `memory.path`), search enrichment via graph expansion, and context injection of related concepts.

## Technical Context

**Language/Version**: TypeScript (strict mode), Bun 1.0+
**Primary Dependencies**: Zod v4 (tool schemas), InversifyJS (DI), Vercel AI SDK (LLM calls via createLlmAdapter)
**Storage**: JSONL file (`~/.slashbot/graph.jsonl`), full in-memory load
**Testing**: Vitest (co-located test files)
**Target Platform**: Linux (Bun runtime)
**Project Type**: Plugin extension (existing slashbot plugin system)
**Performance Goals**: Graph load <500ms, traversal <50ms, extraction <2s async
**Constraints**: <10K nodes, <50K edges, non-blocking extraction, no external graph DB
**Scale/Scope**: Personal bot — few thousand nodes sufficient

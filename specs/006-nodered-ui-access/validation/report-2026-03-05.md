## Bug Found & Fixed: BUG-001

**Issue**: FlowManager API calls returned HTTP 401 when `adminAuth` was enabled — all flow operations (list, create, update, delete) and the FlowChangePoller failed silently.

**Root Cause**: Feature 006 added `adminAuth` to `settings.js` but `FlowManager` made unauthenticated API calls.

**Fix**:
- Added `editorApiToken` (random 32-byte hex token) to `NodeRedConfig`, generated alongside password hash
- Added `adminAuth.tokens` static token block in `generateSettings()` for internal API access
- Added `apiFetch()` wrapper in `FlowManager` that injects `Authorization: Bearer` header when token is configured
- See [BUG-001 report](bugs/BUG-001-flowmanager-api-auth.md)

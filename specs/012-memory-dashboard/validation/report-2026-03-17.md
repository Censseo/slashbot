## Bug Reports

### BUG-001 [CRITICAL] Search-to-Explorer navigation broken — path prefix mismatch

- **File**: `src/plugins/webui/handlers/memory-search.ts`
- **Severity**: Critical
- **User Story**: US2 (Scenario 2.2)
- **Description**: MemoryStore.search() returns paths with `memory/` prefix (e.g., `memory/notes.md`), but file API endpoints expect paths relative to the memory directory (e.g., `notes.md`). Clicking a search result calls `loadFileContent('memory/notes.md')` → `GET /api/memory/files/memory/notes.md` → 404.
- **Fix**: Strip `memory/` prefix from search result paths in the search handler before returning results.

### BUG-002 [LOW] POST /api/memory/notes returns path with memory/ prefix

- **File**: `src/plugins/webui/handlers/memory-notes.ts`
- **Severity**: Low
- **User Story**: US3 (Scenario 3.5)
- **Description**: `store.appendToday()` returns a path with `memory/` prefix (`memory/202603/20260317.md`), but file tree uses paths relative to memory dir (`202603/20260317.md`). Cosmetic issue — frontend doesn't use returned path for navigation.
- **Fix**: Strip `memory/` prefix from the returned path, or document the inconsistency.

### BUG-003 [MEDIUM] Stats not refreshed on tab switch

- **File**: `frontend/public/js/memory.js`
- **Severity**: Medium
- **User Story**: US5 (Scenario 5.2)
- **Description**: FR-043 requires "Stats MUST refresh when the operator switches tabs". T042 removed the `loadStats()` call from `switchTab()` as "redundant" with the 30s polling interval. However, the spec explicitly requires immediate refresh on tab switch, not just polling.
- **Fix**: Re-add `this.loadStats()` call in `switchTab()` method.

## Recommendations

### Quick Wins (< 30 min total)

1. **Fix DIP in runner.ts** — Change `registry?: PluginRegistry` → `registry?: IPluginRegistry` in constructor. The `PluginRegistry` default creation stays but the property type broadens. This aligns `SlashbotRunner` with the `ISlashbotRunner` contract and enables test doubles.
2. **Align metadata Zod schema** — `z.record(z.string(), z.unknown()).optional()` matches the data-model spec form exactly.
3. **Document dangling iterator** — Add JSDoc note to `executeStep` that plugins MUST yield a terminal event (`step_complete` or `error`); callers are responsible for providing their own timeout if needed.

### Short-term (< 1 hour)

4. **Integrate compat test** — Hook `bun run runner:build && node tests/runner/node-compat.mjs` into CI pre-merge validation to catch Node.js regressions automatically.

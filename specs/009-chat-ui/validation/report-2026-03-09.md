## Bugs Found and Fixed During QA

### BUG-001: Static file serving — wrong asset path (FIXED)

- **Severity**: Critical (US1 blocked — page wouldn't load)
- **Root cause**: `paths.workspace('frontend', 'public')` resolves to `{cwd}/.slashbot/frontend/public` (appends `.slashbot`) but frontend files are at `{cwd}/frontend/public`
- **Fix**: Changed webui plugin to use `context.getService<string>('kernel.workspaceRoot')` + `resolve(workspaceRoot, 'frontend', 'public')` directly
- **File**: `src/plugins/webui/index.ts:99-100`

### BUG-002: SSE event format mismatch (FIXED)

- **Severity**: Critical (no text would render)
- **Root cause**: Server emits `{"type":"text-delta","payload":{"text":"..."}}` per 008 contract but `sse-client.js` read `event.delta` (flat format)
- **Fix**: Updated `_processLine()` in `sse-client.js` to extract from `event.payload.*` with flat-format fallback for backwards compatibility
- **Files**: `frontend/public/js/sse-client.js`, `tests/frontend/sse-client.test.ts`

### BUG-003: sessionId validation/generation mismatch (FIXED)

- **Severity**: High (session continuity broken — multi-turn conversation impossible)
- **Root cause**: Server generated `sessionId = "web-{uuid}"` but `ChatRequestSchema` validated incoming sessionIds as strict UUID (rejecting the `web-` prefix)
- **Fix**: Changed sessionId generation to `randomUUID()` (no prefix)
- **File**: `src/plugins/webui/handlers/chat.ts:88`

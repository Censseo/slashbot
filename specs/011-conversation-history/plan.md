# Implementation Plan: Conversation History

**Branch**: `011-conversation-history` | **Date**: 2026-03-17 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/011-conversation-history/spec.md`

## Summary

Persistent conversation storage and browsing for the slashbot web UI. Backend stores conversations as per-file JSONL with a metadata index for fast sidebar loading. Frontend adds a sidebar panel for listing, selecting, creating, and deleting conversations. Extends existing chat handler and Alpine.js chat component. Title generation uses the existing LLM adapter with `noTools` mode.

## Technical Context

**Language/Version**: TypeScript (strict mode) on Bun 1.0+ (backend), JavaScript ES2022+ (frontend)
**Primary Dependencies**: InversifyJS (DI), Zod v4 (validation), Vercel AI SDK (title generation), Alpine.js 3.x (frontend)
**Storage**: JSONL files in `~/.slashbot/web-ui/conversations/` + `index.json` metadata
**Testing**: Vitest — unit tests for ConversationStore, integration tests for API endpoints
**Target Platform**: Linux server (self-hosted), desktop browser
**Project Type**: Web application (backend + frontend)
**Performance Goals**: Sidebar load < 500ms for 100 conversations, message append < 100ms
**Constraints**: No build step for frontend, no new runtime dependencies
**Scale/Scope**: Single user, up to ~1000 conversations, ~500 messages per conversation

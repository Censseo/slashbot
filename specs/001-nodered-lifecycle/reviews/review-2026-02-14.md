- Escape single quotes in settings.ts `userDir` interpolation

- Implement health check failure handling (consecutive failure counter -> restart)
- Refactor `handleProcessExit()` and `stop()` to use `setState()` consistently
- Replace `fs.appendFileSync` with async buffered writes
- Add proper typed event emissions (remove `as any` casts)

### Long-term
- Implement log rotation for nodered.log
- Add structured error types for better error handling
- Consider contract alignment (update contracts or update implementation to match)

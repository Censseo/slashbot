# Node-RED Setup Skill

Manages the Node-RED runtime lifecycle for slashbot. Follow the section that matches the requested task.

## Detect

Check whether Node-RED is installed and available:

1. Run `node --version` to confirm Node.js >= 18.x is present. If not found, stop and report that Node.js is required.
2. Check if Node-RED binary is available: run `"$HOME/.slashbot/nodered/node_modules/.bin/node-red" --version 2>/dev/null || echo "NOT_FOUND"`.
3. If output contains `NOT_FOUND`, Node-RED is not installed locally — proceed to **Install**.
4. If version is printed, Node-RED is installed — proceed to **Start** or **Verify** as appropriate.

## Install

Install Node-RED locally in `~/.slashbot/nodered/`:

1. Create the install directory:
   ```
   mkdir -p "$HOME/.slashbot/nodered"
   ```
2. Detect the package manager to use:
   - Run `npm --version 2>/dev/null` — if it prints a version, use `npm`.
   - Otherwise run `bun --version 2>/dev/null` — if it prints a version, use `bun`.
   - If neither is available, stop and report: "No package manager found. Please install npm (comes with Node.js) or bun."
3. Install Node-RED locally using the detected package manager:
   - With npm: `cd "$HOME/.slashbot/nodered" && npm install node-red`
   - With bun: `cd "$HOME/.slashbot/nodered" && bun add node-red`
4. Verify the binary was created:
   ```
   ls "$HOME/.slashbot/nodered/node_modules/.bin/node-red"
   ```
   If not found, report the install output and stop.
5. Proceed to **Start**.

## Start

Start the Node-RED process:

1. Verify the settings file exists:
   ```
   ls "$HOME/.slashbot/nodered/settings.js" 2>/dev/null || echo "MISSING"
   ```
   If `MISSING`, it will be auto-generated by slashbot's plugin on next init — proceed anyway.
2. Start Node-RED in the background, redirecting logs:
   ```
   "$HOME/.slashbot/nodered/node_modules/.bin/node-red" \
     --userDir "$HOME/.slashbot/nodered" \
     --settings "$HOME/.slashbot/nodered/settings.js" \
     >> "$HOME/.slashbot/nodered/nodered.log" 2>&1 &
   echo $! > "$HOME/.slashbot/nodered/nodered.pid"
   ```
3. Wait 3 seconds for startup:
   ```
   sleep 3
   ```
4. Proceed to **Verify**.

## Stop

Stop a running Node-RED process:

1. Read the PID:
   ```
   cat "$HOME/.slashbot/nodered/nodered.pid" 2>/dev/null || echo "NO_PID"
   ```
2. If `NO_PID`, try finding by process name:
   ```
   pgrep -f "node-red" || echo "NOT_RUNNING"
   ```
   If `NOT_RUNNING`, report "Node-RED is not running" and stop.
3. Send SIGTERM and wait up to 10 seconds:
   ```
   PID=$(cat "$HOME/.slashbot/nodered/nodered.pid")
   kill -TERM "$PID"
   for i in $(seq 1 10); do kill -0 "$PID" 2>/dev/null || break; sleep 1; done
   ```
4. If still running after 10 seconds, send SIGKILL:
   ```
   kill -9 "$PID" 2>/dev/null || true
   ```
5. Remove the PID file:
   ```
   rm -f "$HOME/.slashbot/nodered/nodered.pid"
   ```
6. Report: "Node-RED stopped."

## Restart

Restart Node-RED (stop then start):

1. Follow **Stop** to terminate the running process.
2. Wait 1 second: `sleep 1`
3. Follow **Start** to launch a fresh instance.

If this is a crash recovery attempt, implement exponential backoff:
- Attempt 1: no extra wait
- Attempt 2: wait 5 seconds before starting
- Attempt 3: wait 15 seconds before starting
- After 3 failed attempts, stop and report the error.

## Verify

Confirm Node-RED is healthy:

1. Check the health endpoint:
   ```
   curl -s -o /dev/null -w "%{http_code}" http://localhost:1880/ 2>/dev/null || echo "UNREACHABLE"
   ```
2. If the response code is `200` or `301`, Node-RED is running. Report: "Node-RED is running at http://localhost:1880/".
3. If `UNREACHABLE` or any other code, check the logs:
   ```
   tail -20 "$HOME/.slashbot/nodered/nodered.log" 2>/dev/null || echo "No log file found."
   ```
4. If the log shows a port conflict (e.g., `EADDRINUSE`), report the conflict and suggest the user change the port in `~/.slashbot/nodered/settings.js`.
5. If verification fails after **Start**, wait 5 more seconds and retry once.

## Troubleshoot

Common issues and resolutions:

- **`node-red: command not found`**: The local install is missing. Run **Install**.
- **`EADDRINUSE` port 1880**: Another process is using port 1880. Find it with `lsof -i :1880` and stop it, or change the port in `~/.slashbot/nodered/settings.js`.
- **Node-RED starts but crashes immediately**: Check logs at `~/.slashbot/nodered/nodered.log`. Common causes: corrupted `flows.json`, settings syntax error.
- **`EACCES` permission denied**: The install directory has wrong permissions. Run `chmod -R u+rwx "$HOME/.slashbot/nodered"`.
- **Node.js version too old**: Node-RED requires Node.js >= 18. Check `node --version` and upgrade if needed.
- **PID file stale**: If `nodered.pid` exists but Node-RED is not running, remove the stale file: `rm -f "$HOME/.slashbot/nodered/nodered.pid"`, then run **Start**.
